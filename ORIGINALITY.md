# Bounded distinctiveness assessment

**Mechanism:** Sealed individual probabilities → shared YES/NO/VOID judgment → integer Brier scores and leaderboard.

**Enforced participants/state:** `reveal_deadline` is the COMMIT cutoff; reveals run from then until `resolve_after`. Only the organizer freezes one resolution packet after reveal end. Anyone resolves the frozen packet. Anyone expires unresolved cases to VOID at `resolution_deadline`.

The six releases have different state mechanisms: sealed procurement, calibration scoring, hierarchical grants, selective correction, ordered disclosure review, and three-valued predicate composition.
